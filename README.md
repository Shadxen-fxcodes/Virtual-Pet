Thunder McKing — NASCAR Pet & Racer
A hybrid virtual pet and top-down arcade racer built with HTML, CSS, and JavaScript. Keep Thunder in peak condition in the garage, then take him out to the track to unlock new races and set record lap times.

How to Play

Manage Stats: Keep an eye on Thunder's Fuel, Mood, Energy, and Health.

Pit Stop Care: Use the garage actions (Refuel, Rest, Fix Up, and Change Tires) to keep your car ready for the track. If stats get too low, Thunder's performance will drop.

Race Mode: Hit the track to dodge competitor cars, master cornering, and break lap records. [USE WASD to control the car in the race]

Progression: Keep Thunder happy and win races to unlock new track maps and race events.

Quick Setup

Clone or download this repository.

Ensure all image files inside the assets folder match the filenames in pet_racer.html.

Open pet_racer.html using a local web server (like VS Code's Live Server) to run the game in your browser.
